# Support

## Bugs and feature requests

Use the issue tracker for the project that owns the behavior. Include reproduction steps, expected behavior, environment details, and relevant logs with sensitive information removed.

Use [hanami-osu/infra](https://github.com/hanami-osu/infra/issues) for cross-project work, shared infrastructure, account systems, or questions where the correct repository is unclear.

## Questions and community help

Check the target project's README and existing issues first. For general conversation and community help, join the [Hanami Discord](https://discord.gg/RcGjBZkDP6).

## Supporting development

GitHub sponsorships go to [yorunoken](https://github.com/yorunoken) personally and help support Hanami development and hosting. You can [sponsor yorunoken on GitHub](https://github.com/sponsors/yorunoken).

## Security

Do not use public support channels for vulnerabilities. Follow the [security policy](SECURITY.md).
