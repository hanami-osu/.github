# Contributing to Hanami

Thank you for helping improve Hanami.

## Choose the right repository

Open project-specific bugs and feature requests in the repository that owns the behavior:

- [Hanami Bot](https://github.com/hanami-osu/bot)
- [Hanami Web](https://github.com/hanami-osu/web)
- [osu!guessr](https://github.com/hanami-osu/osu-guessr)
- [Hanami Companion](https://github.com/hanami-osu/companion)

Use [hanami-osu/infra](https://github.com/hanami-osu/infra/issues) for shared infrastructure, account systems, cross-project integrations, organization-wide planning, or work where the correct repository is unclear.

## Before starting

Search existing issues and pull requests first. For substantial or cross-project changes, open an issue before implementation so the scope, migration concerns, and ownership can be agreed upon.

## Pull requests

- Keep each pull request focused on one coherent change.
- Explain the problem, the chosen approach, and any user-visible effects.
- Link the relevant issue when one exists.
- Include the checks you ran and call out anything you could not verify.
- Add screenshots or recordings for visual changes.
- Update documentation when behavior or setup changes.
- Never include credentials, private data, production dumps, or real environment files.

Follow the development and validation commands documented by the target repository. Repository-specific guidance takes precedence over this organization-wide guide.

## Security

Do not report vulnerabilities in a public issue. Follow the organization [security policy](SECURITY.md).

## Licensing

Unless a repository states otherwise, contributions are accepted under that repository's existing license.
